# Kroger 345 downlight: installation sources (LC-UDL-8-A, LC-UDL-8-GR)

Downloaded from the public web on Dino's PC, 2026-10-21, on Dino's approval ("download them").
Source material for the LC installation guide only; `tools/` is never deployed. No prices or quotes.

The downlight is LED Connection's **LC Universal Downlight** (LC-UDL-8: 8 in, 12/16/22W, 3000/3500/4000K,
120-277V 0-10V, IC rated, metal-clad whip; sheet in `tools/specs/lc-existing/` on `feat/flood-spec-sheet`).
Supplier per NetSuite quote export: RZ Lighting / Up-shine. Closest Up-shine model: **UP-DL254-8-22W-OAC3**
(ENERGY STAR: 8 in, 22W, 3000/3500/4000K, Type IC, 0-10V, wet location). **No DL254 installation
instruction exists online**, and the DL254 G2.0 spec sheets on the desk carry no install page.
